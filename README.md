# نظام إدارة المدرسة الذكية المتكامل (Smart School System)

نظام سحابي متكامل لإدارة المدارس والصفوف والكوادر التعليمية والطلاب وأولياء الأمور، مصمم كلياً بأحدث تقنيات الويب السحابية وتطبيق الويب التقدمي (PWA).

## 🚀 التقنيات المستخدمة (Tech Stack)
- **الواجهة والباك إند:** Next.js 14 App Router + TypeScript + Tailwind CSS
- **قاعدة البيانات والمصادقة والريل تايم:** Supabase (Postgres, Auth, Realtime, RLS)
- **تطبيق PWA:** next-pwa مع دعم العمل بدون إنترنت للأوفلاين (Offline)
- **الاستضافة:** Vercel
- **نظام التنبيهات:** Telegram Bot & Supabase Edge Functions

---

## 📱 ميزات النظام
1. **تطبيق ويب تقدمي (PWA):**
   - تثبيت التطبيق بنقرة واحدة على الهواتف (Android / iOS) وأجهزة الكمبيوتر بدون الحاجة لمتاجر التطبيقات.
   - العمل دون اتصال بالإنترنت وحفظ الجدول والدرجات مع صفحة `/offline` مخصصة.
2. **5 لوحات تحكم متخصصة:**
   - **لوحة المدير ومعاونه:** إدارة المعلمين وإرسال روابط واتساب، إدارة الصفوف والشعب، الجدول الأسبوعي مع منع التضارب، نقل الطلاب، تقارير PDF، متابعة الأقساط وترحيل السنة.
   - **لوحة المدرس:** جدول الحصص، تسجيل الغياب بمسح باركود QR بكاميرا الهاتف، إدارة الدرجات، إضافة وتصحيح الواجبات النصية، والملاحظات السلوكية والخطة اليومية.
   - **لوحة الطالب:** جدول اليوم، رسوم بيانية تفاعلية للدرجات والغياب (Chart.js)، تسليم حلول الواجبات، رصيد النقاط والترتيب، ورمز QR الخاص بالحضور.
   - **لوحة ولي الأمر:** متابعة حضور الأبناء الفوري لحظة بلحظة، كشوفات درجات PDF جاهزة للطباعة، متابعة الأقساط المتبقية، وحجز مواعيد مقابلة.
3. **بوت تيليجرام تفاعلي:**
   - إشعارات صباحية للمعلمين بالجدول اليومي الساعة 7:00 صباحاً.
   - تنبيه قبل 10 دقائق من كل حصة دراسية.
   - أوامر تفاعلية: `/دروسي_اليوم` و `/احصائية_اليوم`.
4. **أمان عالي:**
   - تفعيل سياسات الأمان على مستوى الصفوف (Row Level Security - RLS) لحماية بيانات كل مدرسة ومستخدم.

## 🗄️ إعداد قاعدة البيانات في Supabase
1. قم بإنشاء مشروع جديد في [Supabase](https://supabase.com).
2. افتح محرر الـ SQL في سوبابيس (SQL Editor).
3. انسخ محتوى الملف `supabase/migrations/202609240001_complete_school_schema.sql` والصقه واضغط **Run**.
4. اضبط متغيرات البيئة في ملف `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
   TELEGRAM_BOT_TOKEN=your-telegram-bot-token
   ```
